# 新闻感母板 V2 - 完整布局规范（奇迹强调版）

## 母板特点
- **风格**：新闻感｜黑白极简｜右对齐
- **字体**：Source Han Sans（标题） + Long Cang（胶囊）
- **配色**：H1H2白色文字 + 淡米白底胶囊
- **特色**：胶囊中最具情感冲击力的词汇使用绿色强调

## 关键词高亮策略
**选取原则**：情感冲击力 > 传播价值 > 主题相关性

**优先级排序**：
- ✅ **一级**：情感冲击词（"血泪史"、"奇迹"、"逆袭"、"死里逃生"）
- ✅ **二级**：完整痛点概念（"创业血泪史"、"6个奇迹"）  
- ❌ **避免**：普通主题词（"创业"、"投资"、"明星"、"做生意"）

**实际案例**：
- "20年老友揭秘创业血泪史" → 高亮**"血泪史"**
- "6个奇迹让她死里逃生" → 高亮**"奇迹"**
- "从悬崖坠落到重新站立" → 高亮**"重新站立"**

## 区域划分

### 1. 顶部图片区域（67px高度）
- **位置**：top: 20px, left: 20px, right: 20px
- **高度**：固定67px
- **圆角**：12px
- **功能**：显示播客头部信息

### 2. 中间标题区域（核心内容区）
- **位置**：top: 110px, left: 40px, right: 40px
- **层级**：z-index: 10（确保在遮罩之上）
- **对齐**：右对齐（text-align: right）

### 3. 底部图片区域（180px高度）
- **位置**：bottom: 0, left: 0, right: 0
- **高度**：固定180px
- **功能**：显示主持人合照

## 字体字号规则（按标题字数分类）

### 🔸 方案一：H1标题≤7字（标准版本）

#### H1（冲击事实）
- **字号**：48px
- **字重**：800 (Extra Bold)
- **行高**：0.95
- **字距**：-0.01em (-1%)
- **防换行**：white-space: nowrap + overflow: hidden

#### H2（极端后果）
- **字号**：38px
- **字重**：700 (Bold)
- **行高**：1.05
- **字距**：-0.005em (-0.5%)
- **防换行**：white-space: nowrap + overflow: hidden
- **上边距**：margin: 18px 0 0 0

#### 胶囊标签（分色强调）
- **字号**：20px
- **字重**：600 (Semi-bold)
- **字体**：龙藏体 (Long Cang)
- **普通文字色**：深灰 #666
- **强调文字色**：希望绿 #22C55E
- **防换行**：white-space: nowrap
- **上边距**：margin-top: 24px

### 🔸 方案二：H1标题8-14字（紧凑版本）

#### H1（冲击事实 - 紧凑）
- **字号**：48px（保持不变）
- **字重**：800 (Extra Bold)
- **行高**：1.0833（约4px行间距）
- **字距**：-0.01em (-1%)
- **允许换行**：white-space: normal + word-break: keep-all

#### H2（极端后果 - 紧凑）
- **字号**：38px
- **字重**：700 (Bold)
- **行高**：1.05
- **字距**：-0.005em (-0.5%)
- **防换行**：white-space: nowrap + overflow: hidden
- **上边距**：margin: 10px 0 0 0

#### 胶囊标签（分色强调 - 紧凑）
- **字号**：20px
- **字重**：600 (Semi-bold)
- **字体**：龙藏体 (Long Cang)
- **普通文字色**：深灰 #666
- **强调文字色**：希望绿 #22C55E
- **防换行**：white-space: nowrap
- **上边距**：margin-top: 16px

#### 标题区域位置（紧凑）
- **标题区起始位置**：top: 105px（标准版110px上移5px）

```css
/* 紧凑版本样式 - 用于8-14字标题 */
```

## 使用说明
1. 直接复制CSS代码使用
2. 确保引入Long Cang字体（胶囊使用）
3. 胶囊文字需要分别设置span实现分色
4. "奇迹"二字使用绿色强调，其他文字使用深灰色
5. 标题内容不超过容器宽度，避免换行
