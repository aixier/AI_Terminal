# 新闻感母板 V2 - 通用版（高光句子版）

## 📝 版本说明（通用版）

### 适用场景：普通播客创作者
- **目标客户**：个人播客、中小播客工作室
- **核心需求**：通过吸引人的高光句子增强点击率和传播效果
- **标题来源**：从5句高光总结中选择最吸引点击的一句作为封面标题
- **高光总结用途**：1句用于封面标题，4句作为文案内容在JSON中输出

## 母板特点
- **风格**：新闻感｜黑白极简｜右对齐
- **字体**：Source Han Sans（标题）
- **配色**：H1H2白色文字
- **特色**：三层标题结构（H1+H2+胶囊），突出播客主题

## 标题结构设计
**设计原则**：简洁明了 > 信息完整 > 视觉层次

**三层结构**：
- ✅ **H1**：冲击事实句（从高光句子中提取）
- ✅ **H2**：极端后果句（从高光句子中提取）
- ✅ **胶囊标签**：转折悬念句（从高光句子中提取）

**实际案例**：
- 高光句子："19岁收到500元工资，认定老板值得跟随，开启25年深厚友谊"
- H1："19岁收到500元工资" (冲击事实)
- H2："认定老板值得跟随" (极端后果)
- 胶囊："开启25年深厚友谊" (转折悬念)

- 高光句子："2010年入选百大作家榜，书信被质疑非文学，却展现独特艺术价值"
- H1："2010年入选百大作家榜" (冲击事实)
- H2："书信被质疑非文学" (极端后果)
- 胶囊："却展现独特艺术价值" (转折悬念)

**胶囊绿色高亮词选择规则**：
- **选择标准**：情感冲击力 > 传播价值 > 数字/时间词汇 > 动词优于名词
- **优先词汇类型**：时间数字（"25年"）、情感动词（"开启"）、关系词汇（"友谊"）
- **实现方式**：`<span class="capsule-text-highlight">词汇</span>`
- **示例**：
  - "开启25年深厚友谊"中，"25年深厚友谊"设为绿色高亮
  - "却展现独特艺术价值"中，"艺术价值"设为绿色高亮

### 🔸 CSS类自动选择逻辑（实现规范）

**核心原则**：H1统一使用允许换行的样式，适应不同长度的标题

#### JavaScript实现函数

```javascript
function processH1Title(titleText) {
    // 计算字符数（中文字符 + 数字，不计算标点符号）
    const charCount = (titleText.match(/[\u4e00-\u9fa5\d]/g) || []).length;
    
    // H1统一处理：允许换行，保持数字完整性
    const processedText = titleText.replace(
        /(\d+)(元|万|岁|年|次|个|米|天|分|秒|块|张|本|件|套|双|只|头|条|根|支|枚|粒|颗|滴|片|层|段|章|节|页|行|字|句)/g,
        '<span style="white-space: nowrap;">$1$2</span>'
    );
    
    return {
        cssClass: 'title-h1',              // 统一使用允许换行的H1样式
        containerClass: 'title-container',
        processedText: processedText
    };
}

// 兼容旧函数名（向后兼容）
function getH1CSSClass(titleText) {
    const result = processH1Title(titleText);
    return {
        cssClass: result.cssClass,
        containerClass: result.containerClass
    };
}

// 使用示例
const h1Title = "19岁收到500元工资";
const result = processH1Title(h1Title);  
// 返回: { 
//   cssClass: 'title-h1', 
//   containerClass: 'title-container',
//   processedText: '19岁收到<span style="white-space: nowrap;">500元</span>工资'
// }

// HTML生成
const h1HTML = `<h1 class="${result.cssClass}">${result.processedText}</h1>`;
const containerHTML = `<div class="${result.containerClass}">...</div>`;
```

#### 应用流程

```
1. 提取H1标题文本
   ↓
2. 调用 getH1CSSClass(titleText)
   ↓
3. 获取返回值：{ cssClass, containerClass }
   ↓
4. 应用到HTML模板：
   - <h1 class="{cssClass}">
   - <div class="{containerClass}">
   ↓
5. 确保对应的CSS类已定义
```

#### 字数统计规则

- **统计中文字符和数字**：使用正则 `[\u4e00-\u9fa5\d]`
- **不计算标点符号**：逗号、句号等标点不计入字符数
- **数字换行规则**：数字作为整体不能中间断开（如"500"不能换行成"50\n0"）
- **示例**："19岁收到500元工资" = 11个字符（1+9+岁+收+到+5+0+0+元+工+资）→ 使用紧凑版
