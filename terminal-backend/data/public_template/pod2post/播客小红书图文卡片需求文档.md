**播客社媒图文卡片需求文档（整理版）**

<a name="heading_0"></a>**项目介绍**

## 🚀 **项目概述**

**播客卡片生成系统**是一个将任意播客内容自动转化为社媒平台图文卡片的标准化工具。用户只需提供播客文本和照片，系统将自动生成11张精美卡片和配套的社媒发布文案。

### 📥 **输入要求**

**必需文件**：
1. **播客文本**：.txt格式，包含完整播客对话内容（转录文本）
2. **Show Notes**：.txt或.md格式，包含节目背景信息：
   - 准确的嘉宾姓名、主持人姓名
   - 节目标题和期数
   - 重要人物介绍
   - 节目背景信息
3. **照片文件夹**：包含以下照片
   - `封面顶部.png/jpg`：播客头部信息图片
   - `封面合照.png/jpg`：主持人+嘉宾合照
   - **内容页照片**：10张以内随机使用，超过10张自动选择10张
4. **CDN文件夹**：包含背景纹理图片（优先使用本地文件，CDN链接作为备用）
   - `../CDN/封面背景.jpeg`：封面的背景纹理
   - `../CDN/样式1纹理.jpg`：内容页样式1的文字区域背景纹理
   - `../CDN/样式4纹理.jpg`：内容页样式4的整体背景纹理

### 📤 **输出内容**

**标准交付物**：
1. **HTML文件**：包含播客标题 + 11张卡片（1张封面 + 10张内容页）
2. **JSON文件**：社媒发布文案，包含：
   - `title`：封面使用的高光句子
   - `content`：播客文案内容，包含两部分：
     * **5条高光句子**：完整列出提炼的所有高光总结
     * **播客总结**：对播客的整体总结介绍（≤300字）
   - `hashtag`：相关标签（约10个，包含嘉宾姓名、播客标题、内容相关话题等）

### 🔄 **工作流程**

1. **文档解析**：按顺序阅读需求文档 → 封面模板文档 → 内容页模板文档
2. **信息校正**：从Show Notes提取准确的人名、节目信息，校正播客文本中的转录错误
3. **内容提取**：从校正后的播客文本提取5条高光总结 + 10条金句
4. **素材分配**：自动识别照片横竖版，匹配对应样式模板
5. **卡片生成**：封面使用最吸引点击的高光句，内容页对应10条金句
6. **文案生成**：基于提取内容生成社媒发布文案

<a name="heading_0"></a>**完整需求总结**


<a name="heading_1"></a>**🎯 总体目标**

- 将播客长音频内容转化为社媒平台可传播的图文卡片。
- 产出既有"观点总结"，也有"对话氛围"的素材。
- 满足用户在社媒平台上的核心诉求：**真实感 + 共鸣 + 可收藏 + 品牌感**。


  <a name="heading_2"></a>**📌 需求拆解**

  <a name="heading_3"></a>1. **封面页**

- **顶部**：播客贴图（节目封面/截图）
- **底部**：主持人+嘉宾的剧照
- **中间**：一句高光（从提炼出的内容中人工挑选）
- **作用**：吸引点击、定调子

  <a name="heading_4"></a>2. **内容页**

- **内容**：来自播客的金句原文（短金句/长金句对话）
- **形式**：每张卡片 = 金句文本 + 一张真实剧照
- **作用**：增强真实氛围，激发共鸣，促进收藏与转发

  <a name="heading_5"></a>3. **高光总结**

- 数量：5 条
- 定义：描述性事实陈述，概括关键情节，有具体细节和数据支撑，能引发读者好奇和震撼（20-30字左右）
- 用途：

  1、作为封面文字

  2、作为社媒平台主帖正文的骨架

  <a name="heading_6"></a>4. **金句（包括单句和长对话式）**

- 数量：10 条长对话式金句
- 定义：保留嘉宾/主持的原话，带有情绪与对话感
- 结构：每条金句包含6句左右连续对话，保持完整的对话逻辑和情绪起伏
- 用途：

  1、内容页的主体文案（每条对应一张内容页）

  2、也可单独作为"金句卡"补充日更


  <a name="heading_7"></a>5. **工作流程**

### 🔧 **人名校正机制**

**校正原则**：
- Show Notes为权威信息源，以其中的人名为准
- 自动识别播客文本中的人名转录错误并统一校正
- 常见错误类型：同音字（"曲颖"→"瞿颖"）、多字符（"李劲儿"→"李劲"）、变体写法等

**执行步骤**：
1. 从Show Notes提取准确的人名清单
2. 在播客文本中识别相似/错误的人名变体
3. 统一替换为Show Notes中的标准人名
4. 确保HTML输出中的所有人名准确一致

1. **提炼内容**
- 从校正后的播客文本中提炼：

  **1、高光总结** 5 条（描述性事实陈述，有具体细节数据）

  **2、金句** 10 条（真实原话，短句 + 长段落）

2. **制作封面图**（1 张）
- 对应最吸引点击的1条高光总结
- 结构：顶部播客贴图 + 底部剧照 + 中间总结

3. **制作内容页图**（10 张）

🔹 **内容页制作规格**
- **页数**：10张内容页
- **每页内容**：1条金句原文（单人多句或多人对话式）+ 一张真实剧照 + 底部小标题
- **图片使用**：除了封面用过的2张（封面顶部、封面合照），剩余的照片中随机选择10张（不要复用）用于内容页
- **排版样式**：确定使用4种排版样式（详见`内容页模板规范.md`）
  - 样式1：上下分区式（浅色版） - 单人多句金句
  - 样式2：左右分栏式（杂志感） - 单人多句金句  
  - 样式5：阶梯式照片叠加风格 - 多人对话式金句（≤6句）
    **重要**：必须根据实际照片中人脸位置调整background-position（15%-40%三档）
  - 样式4：首句放大式（抓眼） - 单人多句金句
- **小标题规范**：每张内容页底部显示6-8字的内容概括标题，低存在感设计
- **水印规范**：所有内容页必须添加CardPlanet logo水印，严格按照`内容页模板规范.md`中的技术规格实现




  <a name="heading_8"></a>**内容类型与排版建议**


  <a name="heading_9"></a>**🔹 高光总结**

- **定义**：描述性事实陈述，概括关键情节，有具体细节和数据支撑，能引发读者好奇和震撼。
- **结构要求**：每句高光必须包含三个层次，便于拆解为封面标题：
  - **冲击事实句**：震撼的具体事件或数据，避免人名，优先使用事实数据
  - **极端后果句**：事件造成的严重后果（≤8字）
  - **转折悬念句**：意想不到的转机或结局
- **字数限制**：整句不超过25字
- **字号匹配规则**：
  - H2≤7字：字号36px
  - H2=8字：字号34px

- **标准示例**：
- "19岁收到500元工资，认定老板值得跟随，开启25年深厚友谊"（25字）
  - H1（冲击事实句）：19岁收到500元工资（避免人名，突出数据）
  - H2（极端后果句）：认定老板值得跟随（8字，使用34px字号）
  - 胶囊（转折悬念句）：开启25年深厚友谊

- **其他示例**：
- "7年维权败诉，仍不放弃抗争，最终获赔180万"（21字）
- "悬崖坠落重伤，467天康复训练，创造医学奇迹"（23字）

- **使用场景**：
- 封面图（拆解为三段式标题）
- 主帖文案标题/引子




  <a name="heading_10"></a>**🔹 金句（短句 vs 长段落）**

1. **短金句（单句式）**
2. **定义**：简短有力的一句话，像 punchline。

**示例**：

- “坏人没死，我不能先死。”
- “学习速度，比头衔更重要。”

  **使用场景**：

- 封面中间的文字
- 单独成卡，做日更填充


3. **长金句（单人多句式）**
- **定义**：3–6 句连续的单人发言，保留人物的情绪和语气。
- **示例**：
- "当我醒来发现骨头全碎了，但孩子还在，那一刻我知道我要活下去。坏人没死，我不能先死。哪怕每天疼得昏过去，我也要撑住。"
- **使用场景**：样式1、样式2、样式4的内容页主体

4. **多人对话式金句**
- **定义**：≤6句的问答对话，保持完整的对话逻辑和情绪起伏。
- **示例**：
- "所以那时候你觉得我们仨长得好看吗？""关于谁最好看，我跟你说我早年间唱歌手的时候...""真的假的？""真的，当时就全部都是她。"
- **使用场景**：专门用于样式5（阶梯式照片叠加风格）内容页





  <a name="heading_11"></a>**🔹 排版样式（已确定4种）**

**详细实现规范请参考：`内容页模板规范.md`**

1. **样式1：上下分区式（浅色版）**
- 布局：上部65%图片 + 下部38%文字区（重叠8%）
- 特点：磨砂玻璃效果、柔和曲线边缘、温暖感
- 图片要求：横版照片
- 内容类型：单人多句金句原话

2. **样式2：左右分栏式（杂志感）**
- 布局：左侧60%图片 + 右侧40%文字区
- 特点：杂志风格、简洁专业、绿色装饰引号
- 图片要求：竖版照片
- 内容类型：单人多句金句原话

3. **样式5：阶梯式照片叠加风格**
- 布局：全图背景 + 中央文字框
- 特点：强烈代入感、适合多人对话展示
- 图片要求：竖版照片
- 内容类型：多人对话式金句（≤6句）

4. **样式4：首句放大式（抓眼）**
- 布局：上部45%图片 + 下部55%文字区
- 特点：金黄色竖线强调、视觉冲击力强
- 图片要求：横版照片
- 内容类型：单人多句金句原话


  **统一要求**：

- 行宽 ≤12–14 个字
- 一段文字 ≤100 字，超过则拆两张图
- 关键词可加粗或变色，增强视觉冲击

<a name="heading_封面标题"></a>**📋 封面标题新规定**

🔹 **内容选择策略**

从提炼出来的5句高光总结中：
- 选出1句最吸引点击的作为封面标题
- 这句高光要拆解成3段来呈现

🔹 **3段式拆解结构**

按照新闻感母板的层级样式：
- H1：第一段（冲击事实）
- H2：第二段（极端后果）
- 胶囊：第三段（转折悬念）

🔹 **色彩高亮策略**

- H1、H2：保持白色文字
- 胶囊文字：大部分深灰色（#666）
- 胶囊关键词：选择胶囊句中**最具情感冲击力和传播价值**的词汇，使用绿色高亮（#22C55E）

**关键词选取规则**：
- ✅ 优先选择：情感冲击词（"血泪史"、"奇迹"、"逆袭"）
- ✅ 次选：完整痛点概念（"创业血泪史"、"死里逃生"）
- ❌ 避免选择：普通主题词（"创业"、"投资"、"明星"）
- **原则**：情感优先于信息，冲击力优先于准确性

🔹 **实际案例理解**

以"34米悬崖坠落，全身粉碎性骨折，6个奇迹让她死里逃生"为例：
- H1（冲击事实句）：34米悬崖坠落
- H2（极端后果句）：全身粉碎性骨折
- 胶囊（转折悬念句）：6个奇迹让她死里逃生（"奇迹"是核心词，用绿色）

🔹 **应用逻辑**

1. 选出最吸引点击的高光句
2. 拆解成3段层级
3. 识别胶囊句的核心词汇
4. 核心词用绿色，其他用深灰
5. 套用 新闻感封面.md 标题样式


  <a name="heading_12"></a>**✅ 总结**

- **封面**：1 张 → 高光总结（从5条中选择最吸引点击的1条）
- **内容页**：10 张 → 金句（单人多句 or 多人对话）+ 剧照，使用4种确定的排版样式
- **目标效果**：真实感、共鸣感、可收藏、账号视觉统一
- **技术实现**：具体CSS代码和使用规范详见 `内容页模板规范.md`
- **图片分配规则**：
  - 横版照片 → 样式1、样式4
  - 竖版照片 → 样式2、样式5
- **内容分配规则**：
  - 单人多句金句 → 样式1、样式2、样式4  
  - 多人对话金句 → 样式5
