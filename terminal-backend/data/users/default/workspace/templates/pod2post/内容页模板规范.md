# 播客内容页模板规范 V1.0

## 概述
本文档定义了播客内容页的4种排版样式，每种样式都有特定的使用场景、图片要求和内容类型。

## 核心设计原则

### 基础规格
- **卡片尺寸**：375px × 500px（3:4比例）
- **内容来源**：任意播客的真实对话金句
- **图片来源**：除封面使用的2张图片外的其余访谈现场photos
- **设计理念**：保持对话感、情感温度、真实氛围

### 图片使用规则
- **横版photos**：样式1（浅色版）、样式4 专用
- **竖版photos**：样式2、样式3 专用
- **选择原则**：从可用photos中随机选择10张，不重复使用

### 内容类型分配
- **样式1（浅色版）**：单人多句金句原话
- **样式2**：单人多句金句原话  
- **样式3**：多人对话式金句（≤6句）
- **样式4**：单人多句金句原话

## 样式1：上下分区式（浅色版）

### 使用场景
- 情感温暖的内容
- 需要完整展示较长对话的场景
- 访谈感强的单人独白

### 技术规格
- **图片要求**：横版photos
- **内容类型**：单人多句金句原话
- **布局**：上部60%图片 + 下部50%文字区（重叠10%）

### CSS实现代码

```css
/* 样式1副本：温暖浅色版 */
.style1-light {
    display: flex;
    flex-direction: column;
    background: #fff;
    position: relative;
}

.style1-light-image {
    width: 100%;
    height: 60%; /* 6:4比例设计，平衡视觉效果 */
    object-fit: cover;
}

/* 渐变过渡蒙版 */
.style1-light::before {
    content: '';
    position: absolute;
    top: 50%; /* 从图片底部开始渐变过渡 */
    left: 0;
    right: 0;
    height: 120px; /* 96-128px渐变高度 */
    background: linear-gradient(to bottom, 
        transparent 0%, 
        rgba(248,246,242,0.2) 30%,
        rgba(248,246,242,0.6) 70%,
        rgba(248,246,242,0.9) 100%
    );
    z-index: 1;
    pointer-events: none;
}

.style1-light-content {
    position: absolute; /* 改为绝对定位，实现叠加效果 */
    bottom: 0;
    left: 0;
    right: 0;
    height: 50%; /* 增大文案背景区域，提升可读性 */
    padding: 20px;
    background: 
        linear-gradient(rgba(255, 255, 255, 0.85), rgba(255, 255, 255, 0.85)), /* 更亮的纯白遮罩，85%透明度 */
        url('https://images.unsplash.com/photo-1727019820421-7086790014c8?q=80&w=987&auto=format&fit=crop&ixlib=rb-4.1.0&ixid=M3wxMjA3fDB8MHxwaG90by1wYWdlfHx8fGVufDB8fHx8fA%3D%3D');
    background-size: cover;
    background-position: center;
    color: #333;
    display: flex;
    flex-direction: column;
    justify-content: center;
    z-index: 3; /* 确保在照片和渐变之上 */
    box-shadow: 
        0 -4px 16px rgba(0,0,0,0.06), /* 减少阴影强度（浅色版更淡） */
        inset 0 2px 8px rgba(0,0,0,0.05); /* 内部阴影，贴纸效果 */
    backdrop-filter: blur(12px) saturate(180%); /* 进一步增强模糊：8px→12px */
    /* 柔和曲线边缘 */
    clip-path: path('M 0 40 C 150 10, 225 10, 375 0 L 375 500 L 0 500 Z');
}

.style1-light-text {
    font-size: 16px;
    line-height: 1.6;
    margin: 0;
    text-align: left;
}
```

## 内容制作流程

### 1. photos分类与分配
1. 从访谈现场photos中筛选出横版和竖版photos
2. 排除封面已使用的2张photos
3. 随机选择10张photos分配给内容页：
   - 横版photos → 样式1、样式4
   - 竖版photos → 样式2、样式3

### 2. 内容提取与匹配
1. **样式1、2、4**：单人多句金句原话（3-6句连续发言）
2. **样式3**：多人对话式金句（≤6句问答对话）

### 3. 样式选择建议
- **情感类内容** → 样式1（温暖感）
- **专业内容** → 样式2（杂志感）
- **互动对话** → 样式3（沉浸感）
- **重点突出** → 样式4（视觉冲击）

### 设计原则
- **低存在感设计**：小标题作为辅助元素，不能喧宾夺主
- **统一视觉效果**：所有样式保持一致的字号、字重、透明度
- **位置标准化**：统一放置在卡片底部，距离底边8px
- **内容简洁性**：标题长度控制在6-8个汉字，简洁概括内容主题

### 标题内容规则

#### 命名原则
- **主题概括**：用最简洁的词汇概括该页的核心内容
- **情感色彩**：保持中性或轻微的情感倾向，不使用过于强烈的词汇
- **具体性**：避免过于抽象的描述，要让读者能快速理解内容

#### 字数限制
- **建议长度**：6-8个汉字
- **最大长度**：不超过10个汉字
- **最小长度**：不少于4个汉字

#### 内容类型对应
- **样式1、2、4（单人金句）**：以事件、话题、感受为主
  - 示例：投资美甲店的故事、瞿颖的睡过头事件、年轻时的冒险精神
- **样式3（多人对话）**：以对话主题或讨论话题为主
  - 示例：多人对话互动、关于餐厅免单的讨论

#### 实际案例参考
- ✅ **好的标题**：
  - "投资美甲店的故事"（7字，具体事件）
  - "瞿颖的睡过头事件"（8字，具体人物+事件）
  - "蔡明的幽默时刻"（7字，人物+特质）
  - "创业失败的感慨"（7字，主题+感受）
  
- ❌ **避免的标题**：
  - "一个非常有趣的投资经历"（过长）
  - "故事"（过短，信息不足）
  - "震撼人心的创业血泪史"（过于戏剧化）

### 样式规范

#### 样式1（浅色版）小标题
- **位置**：文字内容区域底部居中
- **颜色**：深灰色，30%透明度 `rgba(51, 51, 51, 0.3)`
- **字体**：11px，常规字重(400)
- **装饰**：纯文字，无装饰线条

## 样式5：阶梯式photos叠加风格

### 使用场景
- 需要展示多人对话的连续性和层次感
- 创造独特的视觉层次效果
- 适合对话密集的内容展示

### 设计原理
样式5采用同一张photos复制多层的方式，通过Y轴分层创建阶梯效果：
- **顶部区域**：完整显示人脸
- **底部区域**：分成6个条带，每个条带显示同一段背景图片
- **文字叠加**：在各条带上居中显示对话文案

### 技术规格
- **图片要求**：横版或竖版photos均可
- **内容类型**：多人对话式金句（6句以内）
- **布局原理**：自适应文本行数的条带高度计算

### 样式5核心规则（死规则）

#### 条带高度判断规则
```
如果存在需要2行显示的句子 → 每个条带 = 50px
如果全部句子都是1行显示 → 每个条带 = 40px
```

#### 布局计算公式
```
文案总高度 = 条带高度 × 6句
顶部人脸区域 = 500px - 文案总高度
```

#### 两种标准模式

**50px模式（适用于有2行句子的情况）：**
- 条带高度：50px
- 文案总高：50px × 6 = 300px
- 人脸区域：500px - 300px = 200px（40%）

**40px模式（适用于全部单行句子）：**
- 条带高度：40px  
- 文案总高：40px × 6 = 240px
- 人脸区域：500px - 240px = 260px（52%）

### 实施指南

#### 1. 文本行数判断
在实施前需要判断6句对话中是否存在需要换行的长句子：
- **存在2行句子** → 使用50px模式（默认）
- **全部单行句子** → 添加 `content-single-line` 类使用40px模式

#### 2. 背景图片定位调整（重要！必须根据实际photos调整）
**核心原则**：绝不能使用默认的25%，必须根据实际选用photos中人脸位置灵活调整

根据人物在photos中的位置，灵活调整 `background-position`：
- **人脸偏上** → `center 15%` 或 `center 20%`
- **人脸居中** → `center 25%` 或 `center 30%`  
- **人脸偏下** → `center 35%` 或 `center 40%`

**实施要求**：
1. 查看实际选用的photos
2. 判断人脸在photos中的垂直位置
3. 选择对应档位调整顶部人脸层的百分比值
4. 条带背景根据顶部人脸位置调整：
   - 显示紧挨着顶部人脸区域下方的背景部分
   - 一般比顶部人脸位置增加15-25%
   - 例如：顶部40% → 条带60%，顶部25% → 条带50%

#### 3. 条带背景显示
所有条带都显示同一段背景（紧接着人脸区域后的部分），通过调整 `background-position` 确保视觉连续性。

### 适配原则
1. **简化原则**：按死规则执行，不需要复杂计算
2. **视觉连续性**：所有背景层使用同一张photos
3. **文字可读性**：确保文字在背景上清晰可见
4. **人脸完整性**：顶部区域必须能完整显示人物面部
